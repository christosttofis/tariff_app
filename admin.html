Consumption profiles

Paste the DSO profile CSV directly — the transposed format with time rows and month/day-type columns is accepted as-is. Values are normalised automatically.

Expected EAC format

First row: optional category label (e.g. "Domestic") — skipped.
Second row: header — TIME, Jan_WD, Jan_NWD, Feb_WD, Feb_NWD, … Dec_WD, Dec_NWD
Rows 3–50: time slots 00:30 → 23:30 → 00:00 (48 rows, label = end of slot).

Domestic,,,,,,,,,,,,,,,,,,,,,,,,, TIME,Jan_WD,Jan_NWD,Feb_WD,Feb_NWD,…,Dec_WD,Dec_NWD, 00:30,0.0713,0.0687,0.0582,0.0496,…,0.0691,0.0916, 01:00,0.0682,0.0653,0.0523,0.0429,…,0.0626,0.0855, … 00:00,0.0796,0.0694,0.0673,0.0644,…,0.0798,0.0947,

Column order must be: Jan_WD, Jan_NWD, Feb_WD, Feb_NWD … Dec_WD, Dec_NWD (24 columns after TIME). Trailing comma on each row is fine.

Regulated tariffs

Regulated charges set by CERA that apply on top of all supplier tariffs. Grid usage is voltage-specific; all other charges apply to every tariff.

ℹ How these are applied

Each charge is added to the supplier tariff cost when calculating the customer's total bill.
Grid usage is matched to the tariff's voltage level (LV/MV/HV).
PSO and MDM apply to all voltage levels. FPA is configured per tariff.
